# 撮影記録アーカイブ 運用手順

## 初回利用

東京圏輸送情報システムへ普段のFirebaseメールアドレスとパスワードでログインし、「記録・資料システム」内の「撮影記録アーカイブ」を開きます。写真APIへパスワードは送られません。Firebaseが発行する一時的な認証情報だけで本人確認します。

## 写真を登録する

1. 「写真を追加」を押し、写真をドラッグ＆ドロップします。1回100枚、1枚100MBまでです。
2. 選択した写真ごとにカードが表示されます。タイトルはファイル名から自動作成され、各カードでタイトル・種類・撮影日時・撮影場所・駅・列車番号・タグを個別に変更できます。
3. 複数枚に共通する撮影場所、列車番号、タグ、メモなどは「全写真へ一括適用する情報」へ入力します。写真ごとの入力内容がある項目は個別設定を優先します。
4. 「アップロード開始」を押し、進捗が100%になり「保存しました」と表示されるまで画面を閉じません。
5. 撮影日時、カメラ、レンズ、シャッター速度、F値、ISO、焦点距離、GPSは写真のEXIFから自動で保存されます。EXIFにない項目は後から詳細画面の「編集」で補います。

原本はUbuntu HDD、一覧用の軽量画像は自動生成したサムネイルです。画面一覧で原本を直接読み込まないため、通信量を抑えられます。

## 列車・貨物写真

- 列車写真: 列車番号、始発駅、終着駅、列車種別、始発駅日付、変更事項、撮影場所、駅
- 貨物写真: 上記に加えて輸送経路、記事・備考
- 全写真: 撮影日時、撮影場所、タグ、フリーメモ

列車番号、期間、場所、駅、カメラ、レンズ、タグ、焦点距離を組み合わせて検索できます。

## 共有範囲

- 自分のみ: 所有者だけが閲覧
- 特定ユーザー／グループ: 選択したFirebase利用者だけが閲覧
- 限定リンク: 作成したリンクを知る人だけが閲覧
- 全体公開: 撮影記録アーカイブ利用者の公開一覧へ掲載

「共有メンバー」を開くと、最近利用した候補、届いている申請、フレンド一覧がまとめて表示されます。候補から1回で申請でき、名前またはメールアドレスを2文字以上入力して検索もできます。相手が承認後、写真の編集画面で共有相手に指定できます。複数人を選択してグループも作れます。

## 管理用アカウント

`admin@tayunet-traininfo.com` と `systemadmin@tayunet-traininfo.com` は閲覧・管理専用です。全利用者の写真・アルバムを確認し、撮影情報の修正、共有リンク作成、ゴミ箱への移動・復元、バックアップ出力を行えます。写真およびアルバムの新規登録は画面とAPIの双方で禁止されます。

詳細画面の「限定リンク」では、写真単体のURLを発行できます。アルバム一覧の「限定リンク」ではアルバム全体のURLを発行できます。必要に応じてパスワードと有効期限を設定します。パスワードはリンクと別の連絡手段で渡してください。

## 表示方法

- グリッド: 正方形サムネイルで一覧
- タイムライン: 写真と情報を横長に時系列表示
- カレンダー: 撮影日ごとにまとめて表示
- マップ: EXIF GPSまたは手入力した緯度・経度へピンを表示

## 削除と復元

削除した写真はすぐに消えず、ゴミ箱へ移ります。ゴミ箱の詳細画面から30日以内なら復元できます。30日を過ぎると、一覧取得または新規アップロード時に原本・サムネイル・索引が自動削除されます。

## バックアップ

絞り込み欄の「バックアップ／出力」から、本人の撮影情報をJSONまたはCSV、原本をZIPで取得できます。サーバー管理者は `server/photo-archive/README.md` の手順でSQLiteと写真フォルダを別ディスクへ定期バックアップします。
