# WebATOS情報配信システム

ATOS情報配信システムの画面構成と操作感を参考に、公開Web向けに独自実装したモニタです。

- ODPTプロキシからリアルタイム列車・運行情報を読み込み
- 認証済み環境では `TayunetPrivateData` 経由で時刻表JSONを読み込み
- デモデータは使用せず、外部データが使えないときは未取得状態を表示
- 設定画面は対象外

PC版の保存ページから確認できた画面幅、24pxメニューボタン、13px標準文字、表の配色と検索フォーム寸法を公開版向けに再構成しています。

保存ページ内のセッション情報、WebForms状態値、利用者情報、内部URL、元システム用スクリプトは含みません。

保存コードの静的確認では、元システムはASP.NET WebFormsのフォーム送信とUpdatePanelによる部分更新を使用しており、公開JSON APIは確認できませんでした。元システムへの推測リクエストや認証回避は行わず、この公開版ではODPTプロキシと認証済み時刻表APIのみを利用します。
